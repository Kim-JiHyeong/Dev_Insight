# DEV INSIGHT

GitHub 포트폴리오에서 개발자의 강점과 개선 방향을 발견하는 AI 기반 서비스의 UI/UX 프로토타입입니다. 현재 버전은 고정 샘플 데이터로 구성되어 실제 GitHub API 또는 AI 분석을 수행하지 않습니다.

## 개발 목적

저장소 목록만 확인하는 데 그치지 않고 프로젝트 경험과 개발 활동을 돌아보며 취업 및 커리어 준비에 활용할 구체적인 성장 방향을 제공하는 서비스를 기획합니다. MVP에서는 전체 사용자 흐름과 결과 대시보드를 체험할 수 있습니다.

## 주요 사용자

- 컴퓨터공학과 재학생 및 졸업생
- GitHub 포트폴리오를 정리하는 취업 준비생
- 프로젝트 경험과 기술 스택을 객관적으로 살펴보고 싶은 개발자

## 핵심 기능과 이용 흐름

1. 메인 페이지에서 서비스와 분석 항목을 확인합니다.
2. GitHub 프로필 주소를 입력하거나 샘플 프로필을 선택합니다.
3. 다섯 단계로 구성된 데모 분석 진행 화면을 확인합니다.
4. 결과 대시보드에서 종합 점수, 기술 스택, 활동, 강점, 개선점, 액션 플랜과 개발 미션을 확인합니다.

## 화면 구성

- **홈:** 서비스 소개, 프로필 입력, 샘플 분석, 분석 항목과 결과 미리보기
- **분석 진행:** 프로필 확인부터 종합 평가까지의 단계 표시
- **분석 결과:** 종합 평가, 활동 지표, 기술 스택, 강점, 개선 방향, 개발 미션

모든 화면은 반응형으로 구성하고 진행·결과 화면에 샘플 데이터 안내를 표시합니다.

## 기술 스택

- React, Vite, JavaScript, CSS
- lucide-react

## 디렉터리 구조

```text
.
├── index.html
├── package.json
├── README.md
└── src/
    ├── main.jsx       # 화면, 흐름, 샘플 분석 데이터
    └── styles.css     # 반응형 디자인
```

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 실행합니다.

## 초기 MVP 범위

고정 샘플 분석, 프로필 URL 형식 검증, 진행 화면과 대시보드를 제공합니다. 실제 GitHub 데이터 수집, AI API, 로그인, 결과 저장, PDF, 비교, 결제는 포함하지 않습니다. 사용자 이름이 결과에 표시되어도 결과 지표는 실제 계정 데이터가 아닙니다.

## 향후 개발 예정

- GitHub REST/GraphQL API로 프로필, 저장소, README 및 활동 수집
- LLM 기반 프로젝트 분석과 근거가 포함된 피드백 생성
- 직무·수준별 맞춤 로드맵과 개발 미션
- 결과 저장, 이전 분석 비교, PDF 내보내기
- 직무별 분석 기준 및 기업 요구 역량 비교
